- **`bf firstmate` starts the harness you are actually using (#66).** It took the first verified harness on PATH, and `claude` is first in that list — so typing `bf firstmate` inside a Codex session on a machine with both installed handed back Claude. The session you are in now wins: `CODEX_SESSION_ID`, `CLAUDECODE`, `CURSOR_AGENT`, `GROK_AGENT`, `PI_CODING_AGENT` and `OMP_EXT` identify the running harness, taken from what each one actually sets rather than guessed. After that come `firstmate.harness` if you stated one, then the harnesses your install actually wired (from `last-install.json`), and only then the shipped order. An explicit `--harness` still wins outright even when that harness is not installed, so the refusal says "not on PATH" instead of quietly handing you something else, and a signal pointing at something uninstalled steps aside rather than blocking the fallback.
