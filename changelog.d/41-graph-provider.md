- **A real code graph is used when you have one (#41 phase 2).** `knowledge.graph.provider` chooses which graph answers structural questions: `auto` (default) prefers a detected code-graph MCP server and falls back to the builtin regex import map, `builtin` pins the map, and an explicit server name uses that one. Detection is by the shape of a server's tools rather than its name — two matches from `search_graph`, `trace_path`, `query_graph`, `get_architecture`, `get_code_snippet`, `index_repository` — because a name is not a contract and one lone search tool cannot answer a structural question. A named provider that is not available is an error rather than a quiet fall back to regex import edges, which nothing in an answer would reveal. `--doctor` reports the configured value, what it resolved to, and why.
