# T-005 Install a turn-end guard so the lead cannot silently end a turn while the fleet is still working. Th

## Problem
Install a turn-end guard so the lead cannot silently end a turn while the fleet is still working. The installer currently writes no hooks at all.

1. In setup.mjs add a step that registers a Claude Code `Stop` hook in the settings file the installer already manages for Claude Code (find how the installer locates user and project scope; follow the same scope logic, the same marker/idempotency approach and the same rolling .bak convention used by the other writers in that file).

2. The hook runs: node <abs path to model-gateway/dist/index.js> --fleet-check --hook
   Add the `--hook` variant to that CLI branch in model-gateway/src/index.ts: it prints Claude Code Stop-hook JSON. When blocking is true print {"decision":"block","reason":"<short summary: N jobs running, M events pending, and what to call>"}. When blocking is false print nothing and exit 0. It must ALWAYS exit 0 and must never print anything on stderr that could corrupt the hook contract.

3. Make it removable: --uninstall must strip the hook entry and leave any unrelated user hooks in that settings file untouched.

4. Make it honest in --doctor: report whether the turn-end guard is installed.

5. Add assertions to setup/selftest.sh covering install, idempotent re-install, and clean removal, in the style of the checks already in that file.

Do NOT change any unrelated installer step. Do NOT run git commands.

## Acceptance criteria
`npm test` stays green. The hook JSON contract is exercised by a test in model-gateway/test/fleet.test.mjs (or a new file): running the CLI with --fleet-check --hook on a settled fleet prints nothing and exits 0, and on a blocking fleet prints valid JSON whose decision is 'block'. setup/selftest.sh gains assertions for install, re-install and removal. Never write a hook entry twice on re-install.

## Outcome
The turn-end guard shipped in #9: the installer writes one Claude Code Stop hook calling --fleet-check --hook, which blocks while the fleet is busy and prints nothing when settled.
