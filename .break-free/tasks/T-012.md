# T-012 Install a turn-end guard so the lead cannot silently end a turn while the fleet is still working. se

## Problem
Install a turn-end guard so the lead cannot silently end a turn while the fleet is still working. setup.mjs writes no hooks at all today.

1. In setup.mjs add a step registering a Claude Code `Stop` hook in the settings file the installer already manages for Claude Code. Follow the existing scope logic (user vs project), the same marker/idempotency approach, and the same rolling .bak convention used by the other writers in that file.

2. The hook runs: node <abs path to model-gateway/dist/index.js> --fleet-check --hook
   Add the `--hook` variant to that CLI branch in src/index.ts: print Claude Code Stop-hook JSON. When blocking is true print {"decision":"block","reason":"<short summary: N jobs running, M events pending, and which tool to call>"}. When blocking is false print nothing. ALWAYS exit 0, and never write anything to stderr that could corrupt the hook contract.

3. Removable: --uninstall strips the hook entry and leaves unrelated user hooks in that settings file untouched.

4. Honest in --doctor: report whether the turn-end guard is installed.

5. Add assertions to setup/selftest.sh covering install, idempotent re-install, and clean removal, in the style of the checks already there.

Do NOT change any unrelated installer step. Do NOT run git commands.

## Acceptance criteria
Tests stay green. Add a test asserting the hook contract: running the built CLI with `--fleet-check --hook` on a settled fleet prints nothing and exits 0, and on a blocking fleet prints valid JSON whose decision is 'block'. setup/selftest.sh gains assertions for install, idempotent re-install and clean removal. Re-installing must never write the hook entry twice.
