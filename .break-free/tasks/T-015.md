# T-015 Install a turn-end guard so the lead cannot silently end a turn while the fleet is still working. se

## Problem
Install a turn-end guard so the lead cannot silently end a turn while the fleet is still working. setup.mjs writes no hooks at all today.

1. In setup.mjs add a step registering a Claude Code `Stop` hook in the settings file the installer already manages for Claude Code. Read how the installer locates user vs project scope and follow it exactly, along with the same marker/idempotency approach and the same rolling .bak convention used by the other writers in that file.

2. The hook runs: node <abs path to model-gateway/dist/index.js> --fleet-check --hook
   Add the `--hook` variant to that CLI branch in src/index.ts: print Claude Code Stop-hook JSON. When blocking is true print {"decision":"block","reason":"<short summary: N jobs running, M events pending, and which tool to call>"}. When blocking is false print nothing. ALWAYS exit 0, and never write to stderr, which would corrupt the hook contract.

3. Removable: --uninstall strips the hook entry and leaves unrelated user hooks in that settings file untouched.

4. Honest in --doctor: report whether the turn-end guard is installed.

5. Add assertions to setup/selftest.sh covering install, idempotent re-install and clean removal, in the style of the checks already there.

Do NOT change any unrelated installer step. Do not run git commands.

## Acceptance criteria
setup.mjs installs, re-installs idempotently and cleanly removes the Stop hook, touching no unrelated hook entries. --fleet-check --hook prints nothing on a settled fleet and valid block JSON on a blocking one, always exit 0. --doctor reports the guard. selftest.sh has the three new assertions.
