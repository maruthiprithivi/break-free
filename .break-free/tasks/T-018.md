# T-018 Install a turn-end guard, so the lead cannot silently end a turn while the fleet is still working. s

## Problem
Install a turn-end guard, so the lead cannot silently end a turn while the fleet is still working. setup.mjs writes no hooks at all today.

1. In model-gateway/src/index.ts extend the --fleet-check branch: when the argv also contains `--hook`, print Claude Code Stop-hook JSON instead of the plain object. Blocking prints {"decision":"block","reason":"<short: N job(s) running, M event(s) pending — call fleet_status to collect them>"}. Not blocking prints nothing at all. Always exit 0. Never write to stderr in this mode: anything on stderr can corrupt the hook contract.

2. In setup.mjs add a step that registers that Stop hook in the Claude Code settings file the installer already manages. Read how the installer picks user vs project scope and follow it exactly, with the same marker/idempotency approach and the same rolling .bak convention the other writers use. The command is: node <abs path to model-gateway/dist/index.js> --fleet-check --hook

3. --uninstall removes the hook entry and leaves every unrelated hook in that file untouched.

4. --doctor reports whether the turn-end guard is installed.

5. Add assertions to setup/selftest.sh for install, idempotent re-install (the entry must appear exactly once) and clean removal, in the style of the checks already in that file.

Do not change any unrelated installer step. Do not run git commands.

## Acceptance criteria
--fleet-check --hook prints nothing on a settled fleet and valid block JSON on a blocking one, always exit 0, nothing on stderr. setup.mjs installs, re-installs without duplicating, and removes cleanly. --doctor reports the guard. selftest.sh has the three assertions.
