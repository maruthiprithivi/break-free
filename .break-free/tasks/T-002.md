# T-002 Make harness sub-agent sessions visible, so a user can watch or type into one.

## Problem
Make harness sub-agent sessions visible, so a user can watch or type into one.

1. In model-gateway/src/harnessctl.ts export:
   export function attachCommand(s: HarnessSession): string
   returning `tmux attach -t <s.tmux>`. If config.harness.tmux (or env BREAK_FREE_TMUX) is not plain `tmux`, use that binary name instead. Keep it a pure function over the session plus the binary name; add a small method on HarnessController that supplies the binary if that is cleaner.

2. In model-gateway/src/index.ts include the attach command in the JSON returned by harness_spawn, harness_list and harness_status, as a field named `attach`. For harness_list every row gets it.

3. Update those three tool descriptions to say the session can be watched or typed into directly with that command. Keep the wording short and factual.

Do NOT change spawn/send/read semantics. Do NOT touch any other file. Do NOT run git commands.

## Acceptance criteria
Add tests to a NEW file model-gateway/test/attach.test.mjs in the style of test/gateway.test.mjs: harness_spawn returns an `attach` string that contains the tmux session name, and harness_list rows carry the same field. The existing harness test in gateway.test.mjs must still pass unchanged. `npm test` green.
